# Small Python Experiments

Use this folder for short Python programs and learning experiments that are separate from the main Streamlit application.

## Good examples
- A small program that solves a quadratic equation
- A unit converter
- A script that calculates resistor colour-code values
- A simple motor RPM converter

## Important
- Save experiments as separate files, for example `experiments/quadratic_solver.py`.
- Do not replace the root `app.py` with practice code.
- Keep reusable functions in their own modules when a project grows.
- Test a small script locally before adding it to the live MechaTools app.

The Streamlit app runs from the root file: `app.py`.
